# FilaSmart

Sistema de gerenciamento de filas virtuais desenvolvido como projeto acadêmico da Facens.

## Sobre o projeto

O FilaSmart tem como objetivo facilitar o gerenciamento e o acompanhamento de filas de atendimento.

A plataforma permite que usuários entrem em filas virtuais, acompanhem sua posição e recebam notificações quando estiverem próximos de serem atendidos.

Para os estabelecimentos, o sistema oferece recursos para gerenciamento das filas, chamada de clientes e acompanhamento das informações de atendimento.

## Objetivos

* Reduzir o tempo de espera presencial.
* Permitir o acompanhamento da posição na fila.
* Facilitar o gerenciamento das filas pelos estabelecimentos.
* Melhorar a experiência dos usuários durante o atendimento.
